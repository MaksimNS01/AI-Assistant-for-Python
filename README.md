# RAG System with Safety Guardrails
Система вопросно-ответного поиска по документам с интегрированными механизмами безопасности. Реализует гибридную поисковую систему с использованием современных языковых моделей и систем контроля контента.

## Функциональность
* Гибридный поиск по документам (векторный + BM25)  
* Интеллектуальное переранжирование результатов  
* Генерация ответов на основе контекста  
* Многоуровневая система безопасности запросов и ответов  
* Поддержка различных форматов документов  
* Эффективная работа с большими языковыми моделями  

## Технологии
* Python 3.8+  
* LlamaIndex - фреймворк для RAG-систем  
* Hugging Face Transformers - языковые модели  
* Saiga Mistral 7B - основная языковая модель  
* NeMo Guardrails - система безопасности  
* PEFT/LoRA - эффективная тонкая настройка  

## Особенности работы
Процесс обработки запроса  
* Валидация ввода: Проверка запроса системой безопасности  
* Гибридный поиск: Векторный поиск + BM25  
* Переранжирование: Интеллектуальная сортировка результатов  
* Генерация ответа: Формирование ответа на основе контекста  
* Валидация вывода: Проверка сгенерированного ответа
